# Σύγχρονη Μνήμη RAM 2048x16 (Επίπεδο Συμπεριφοράς)

Αυτό το αποθετήριο περιέχει την περιγραφή VHDL σε επίπεδο συμπεριφοράς (behavioral level) για μια σύγχρονη μνήμη RAM μεγέθους 2048 λέξεων των 16-bit. Η υλοποίηση ακολουθεί συγκεκριμένες προδιαγραφές διαχωρισμού λειτουργιών στα μέτωπα του ρολογιού και υποστηρίζει ασύγχρονη ενεργοποίηση.

## Προδιαγραφές & Λειτουργία

Η σχεδίαση της μνήμης υλοποιεί την παρακάτω συμπεριφορά χρονισμού, διαχωρίζοντας τη δειγματοληψία διεύθυνσης και δεδομένων στα δύο μέτωπα του ρολογιού:

* **Ασύγχρονο Chip Enable (CE):** Το σήμα `CE` λειτουργεί εντελώς ασύγχρονα με το ρολόι. Όταν `CE = '0'`, η μνήμη αδρανοποιείται, οι εσωτερικοί καταχωρητές διεύθυνσης μηδενίζονται και η έξοδος των δεδομένων (`Data_out`) διατηρείται στο μηδέν (0).
* **Ανερχόμενο Μέτωπο (Rising Edge):** Όταν το `CE` είναι '1', σε κάθε θετικό μέτωπο του σήματος `Clk` πραγματοποιείται η δειγματοληψία και αποθήκευση της διεύθυνσης `Addr` σε έναν εσωτερικό καταχωρητή (`index`).
* **Κατερχόμενο Μέτωπο (Falling Edge):** Στο αρνητικό μέτωπο του ρολογιού, εκτελείται η κύρια λειτουργία εγγραφής ή ανάγνωσης με βάση το σήμα `w_r`:
* **Εγγραφή (w_r = 1):** Τα δεδομένα εισόδου (`Data_in`) αποθηκεύονται στη διεύθυνση μνήμης που διαβάστηκε στο προηγούμενο ανερχόμενο μέτωπο.
* **Ανάγνωση (w_r = 0):** Τα δεδομένα της επιλεγμένης διεύθυνσης εξάγονται στον δίαυλο `Data_out`.



## Διεπαφή (Ports)

| Σήμα | Κατεύθυνση | Εύρος (Bits) | Περιγραφή |
| --- | --- | --- | --- |
| `Clk` | IN | 1 | Σήμα ρολογιού συστήματος. |
| `CE` | IN | 1 | Chip Enable (Ενεργό στο '1', Ασύγχρονο Reset στο '0'). |
| `w_r` | IN | 1 | Σήμα ελέγχου Εγγραφής/Ανάγνωσης (1 = Εγγραφή, 0 = Ανάγνωση). |
| `Addr` | IN | 11 | Δίαυλος διεύθυνσης (Διαχείριση 2048 λέξεων, `10 downto 0`). |
| `Data_in` | IN | 16 | Δίαυλος δεδομένων εισόδου (`15 downto 0`). |
| `Data_out` | OUT | 16 | Δίαυλος δεδομένων εξόδου (`15 downto 0`). |

## Δομή Αποθετηρίου (Repository Structure)

Για τη διατήρηση ενός καθαρού περιβάλλοντος χωρίς περιττά αρχεία προσωρινής μνήμης του Vivado, το project είναι οργανωμένο ως εξής:

* `/src`: Περιέχει τον πηγαίο κώδικα της σχεδίασης (`RAM_2048x16.vhd`).
* `/sim`: Περιέχει το αρχείο δοκιμής (Testbench) για την προσομοίωση (`RAM_2048x16_tb.vhd`).
* `/waveform`: Περιέχει το αρχείο ρυθμίσεων της κυματομορφής (`.wcfg`) για οπτικοποίηση των σημάτων στο Vivado Simulator.
* `/tcl`: Περιέχει το script `build_ram.tcl` για την αυτόματη επαναδημιουργία του Vivado Project.

## Οδηγίες Αναπαραγωγής (Vivado)

Για να ανοίξετε το project στο Xilinx Vivado:

1. Κατεβάστε το αποθετήριο (Clone / Download ZIP).
2. Ανοίξτε το Vivado.
3. Στην κονσόλα (Tcl Console) στο κάτω μέρος, πλοηγηθείτε στον φάκελο `tcl` χρησιμοποιώντας την εντολή `cd`.
4. Εκτελέστε την εντολή: `source build_ram.tcl`.
5. Το Vivado θα δημιουργήσει αυτόματα το project, θα συνδέσει τα αρχεία από τους φακέλους `src` και `sim`, και θα είναι έτοιμο για Simulation (Run Behavioral Simulation).
